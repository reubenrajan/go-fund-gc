# Grace Chapel — Plans & Projects

Architectural Mission Control for the Grace Chapel Kannuru Plans & Projects programme.

## Foundation

This repository contains the initial Astro implementation, canonical project data, product research register, accessibility-oriented responsive UI, data validation, and GitHub Pages deployment workflow.

## Important data rule

Alternatives, missing models, missing budgets, and unresolved procurement details are preserved. The site must not present an alternative or inferred product as the selected/installed product.

## Development

```bash
npm install
npm run dev
npm run validate:data
npm run build
```

See `docs/BUILD_STATUS.md` for implementation status.
